📖 Sổ Tay Hướng Dẫn Sử Dụng JMeter Web UI

Tài liệu hướng dẫn trực quan toàn diện dành cho Performance Tester & Automation QA với hình ảnh chụp thực tế từ trình duyệt.

🌟 1. Giới thiệu tổng quan & Giao diện chính

JMeter Web UI là ứng dụng web hiện đại, mượt mà được xây dựng trên nền tảng React, TypeScript và Vite, kết nối trực tiếp với Apache JMeter Engine chạy trên máy tính của bạn.

📸 Hình 1: Giao diện làm việc chính với Cây Test Plan, Thanh công cụ Toolbar và Trình soạn thảo 🔍 Click ảnh để phóng to

2 Chế độ thực thi linh hoạt

  • Real JMeter Execution Mode (Chế độ thật): Hệ thống tự động biên dịch Test Plan thành file XML .jmx và khởi chạy tiến trình Java JMeter Non-GUI (jmeter.bat -n -t ...), nạp kết quả và báo cáo HTML thời gian thực.
  • Mock Simulation Mode (Chế độ mô phỏng): Chạy mô phỏng kiểm thử nhanh không cần môi trường Java, phù hợp để dựng nhanh luồng kịch bản.

Cấu hình & Nhận diện tự động

Bấm vào nút huy hiệu Mode Badge ở góc phải thanh công cụ để mở hộp thoại cài đặt đường dẫn JMeter:

📸 Hình 2: Hộp thoại cấu hình đường dẫn và nhận diện phiên bản Apache JMeter

🌲 2. Quản lý Cây kịch bản (Test Plan Tree)

Cây kịch bản bên trái quản lý toàn bộ cấu trúc phân cấp các thành phần kiểm thử theo đúng chuẩn Apache JMeter.

Menu ngữ cảnh chuột phải (Context Menu)

Click chuột phải vào bất kỳ node nào trên cây để mở menu thao tác phân nhóm:

  • Add: Phân nhóm chuẩn (Threads, Samplers, Logic Controllers, Pre/Post Processors, Assertions, Timers, Listeners).
  • Import from cURL…: Nhập nhanh request từ cURL vào node đang chọn.
  • Cut / Copy / Paste / Duplicate / Remove / Rename (F2).
📸 Hình 3: Menu ngữ cảnh chuột phải với danh mục thành phần phân loại chuẩn JMeter

Kéo thả (Drag & Drop) và nạp file

Hỗ trợ kéo thả sắp xếp các node trong cây hoặc kéo thả file .jmx, .jtl, .csv trực tiếp từ máy tính vào trình duyệt:

📸 Hình 4: Giao diện cấu hình CSV Data Set Config và danh sách node trên cây

⚡ 3. Tính năng Import từ cURL (Tools -> Import from cURL)

Nhập nhanh bất kỳ request API nào từ DevTools của trình duyệt hoặc Postman thành component JMeter chỉ trong vài giây.

Cơ chế tự động đồng bộ dữ liệu (Asset Sync)

💡 Tự động sao chép file data:
Hệ thống tự động sao chép các thư mục data/ (ví dụ data/provinces.csv), GPKD/, downloads/ vào thư mục chạy runs/run_XXXX/ để hàm FileServer.getFileServer().getBaseDir() luôn tìm thấy file chính xác 100%.
